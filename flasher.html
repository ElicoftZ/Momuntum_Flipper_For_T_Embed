What this port adds

On top of the Flipper Zero ESP32 port, which already provides NFC, Sub-GHz, Infrared, 125 kHz RFID, Bad USB, WiFi, NRF24, BLE Spam, Archive and Clock. Everything below is new here.

Momentum

  • Momentum settings app — 12 pages, 29 settings, one source of truth
  • Asset packs — swap the whole icon and font set from the card
  • 9 main-menu styles, plus a menu editor to add, remove and reorder entries
  • Lockscreen customisation — time, date, seconds, statusbar, prompt, transparency
  • Lock on boot and locked USB / BLE RPC toggles
  • Dolphin XP and mood editor, sad timer, unlocked animations
  • Passport on a double Back press
  • Statusbar and file-browser options, dark mode
  • Device name editor

Built for this board

  • Rotation-only navigation — every menu, the number keyboard and the infrared button panels reworked for a wheel and three buttons, no D-pad
  • Bluetooth clock sync — the board has no battery-backed RTC, so it reads the time from a bonded phone
  • Backup and restore of settings and Bluetooth bonds
  • Idle dim and deep sleep, returning to the app you were inBETA
    Waking back into the app you left is still being tested — a deliberate power-off or reboot always lands on the desktop.
  • Wake mode in the lock menu
  • Welcome slideshow built into the firmware

New apps

  • Power Profiler with a live battery page
  • Backup Settings
  • Audio suite on the onboard mic — level meter, logger, sonar, waterfall, tone generator, ultrasonic, voice notes
  • Tools — analog clock, Caesar cipher, counter, multi-counter, pomodoro, text viewer, VIN decoder, Ford radio code, trackerflipx
  • Tetris

Protocol additions

  • Sub-GHz — Allstar Firefly and Nord Ice, plus extended range and an editable frequency list
  • NFC — SZPPK, SK and SEVPPK transit parsers
  • Infrared — Blu-ray, monitor and digital-sign universal remotes
  • BLE Spam — name flood and Lovespouse payloads
